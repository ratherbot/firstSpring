Дз по БД:

а) создать контроллер, в котором:
1.  endpoint, который на вход будет принимать данные в виде:
{
  "name": "Мой список дел",
  "events": ["дело1", "delo2", "delo3"]
}
и сохранять их в базу
2.  endpoint, который будет отдавать данные из бд в виде:
[
  {
    "name": "Мой список дел",
    "events": ["дело1", "delo2", "delo3"]
  },
  {
    "name": "Мой список дел2",
    "events": ["дело1", "delo2", "delo3"]
  }
]
б) спроектировать структуру БД для этих данных. В качестве БД можно взять любую БД

Использованы:

Spring Data JPA – для работы с базой данных через объекты. С его помощью реализована сущность TodoList, которая хранит название и список событий.

H2 – встроенная in-memory база данных, что удобно для разработки и тестирования. Для её использования я добавил зависимость com.h2database:h2 в Gradle.

REST контроллер – создан класс контроллера с двумя endpoint'ами:

POST /todolists – принимает JSON с названием и списком дел, сохраняет его в базу.

GET /todolists – возвращает все сохранённые списки дел в виде JSON.

DTO (Data Transfer Object) – используется для передачи данных между клиентом и сервером, отделяя внутреннюю модель от внешнего API.

JPA аннотации – такие как @Entity, @Table, @ElementCollection, для описания структуры таблиц в базе данных.

Настройки через application.properties – конфигурация подключения к базе данных и запуск H2-консоли для отладки.
