## Задание:

1. **Конфиги:**
   - Создать 3 профиля - `dev`, `test`, `prod`, каждый из которых будет включать в себя:
     - a) Конфиг с листом из нескольких значений.
     - b) Название приложения.
     - c) Конфиг с переменной окружения, по дефолту значение - `default`.

2. **Бины:**
   - a) Один бин создается, только если профиль `test`.
   - b) Другой бин создается, если существует первый бин.
   - c) Третий бин создается, если в конфиге `EXAMPLE_TEST` (или переменная окружения `app.env`) не "default".

3. **Валидация:**
   - Сделать валидатор – один кастомный и какой-нибудь стандартный. Повторить примеры, которые обсуждали на лекции.
     1. Сделать свою аннотацию и свой кастомный валидатор с красивым ответом в случае возникновения ошибок.
     2. Создать аннотацию для валидации, объединяющую несколько других аннотаций.
